# 季後賽創造與編輯教學

本教學說明如何在後台**創造**季後賽籤表，以及之後如何**編輯**季後賽的比賽（時間、場地、比分等）。

---

## 前提：賽事類型與例行賽

- 季後賽功能僅適用於 **賽季制（Season Play）** 賽事。
- 必須先有**例行賽**（Round 0），且**例行賽全部打完**後，才能產生季後賽籤表。
- 若賽事是「單淘汰」類型，沒有季後賽，請直接使用籤表頁。

---

## 一、創造季後賽（三步驟）

### 步驟 1：建立賽季制賽事並加入選手

1. 登入後台 → **Create Event**（建立賽事）。
2. **Tournament Type** 選擇 **Season Play (Regular Season + Playoffs)**。
3. 填寫賽事名稱、日期、地點等後建立。
4. 進入該賽事的 **管理選手**（Players）頁，新增所有選手或隊伍。

### 步驟 2：設定季後賽籤表結構並產生例行賽

1. 在同一個 **管理選手** 頁面，找到 **「Season Play - Generate Matches」** 區塊。
2. 設定 **Number of Groups**（分組數）：例如 2 組，選手會隨機分到各組。
3. 設定 **Number of Playoff Teams**（每組前幾名進季後賽）：
   - **Top 2**：每組前 2 名 → 共 2×組數 隊進季後賽  
   - **Top 4**：每組前 4 名  
   - **Top 8**：每組前 8 名  
4. 看下方 **「季後賽籤表結構」** 預覽，確認幾隊進季後賽、會有哪些輪次（八強／準決賽／決賽／季軍賽）。
5. 點 **「🏁 Generate Regular Season」**（產生例行賽）。
6. 確認後，系統會產生所有例行賽對戰（每組內循環），此時**還沒有**季後賽。

### 步驟 3：打完例行賽後產生季後賽

1. 到 **管理籤表 / Matches** 頁，把**所有例行賽**都打完（輸入比分、選勝方、儲存）。
2. 回到 **管理選手** 頁，找到同一個 **Season Play - Generate Matches** 區塊。
3. 點 **「🏆 Generate Playoffs (Top X)」**（X 為你設定的每組晉級名額）。
4. 確認後，系統會依**各組戰績**取前 N 名，自動產生**季後賽籤表**（單淘汰＋季軍賽）。

產生完成後：

- **籤表頁（Draw）**：可切換「例行賽 / 戰績 / **季後賽**」分頁，看到季後賽 bracket。
- **前台**：進入該運動的 **季後賽** 頁籤，也會看到同一份季後賽籤表。

---

## 二、編輯季後賽（時間、場地、比分）

季後賽的「對戰組合」由系統依戰績自動排定，**不能**在後台手動改誰打誰；但每一場季後賽的**時間、場地、比分、狀態**都可以編輯。

### 編輯單場季後賽

1. 後台 → 該賽事 → **管理籤表（Matches）**。
2. 上方篩選 **Round** 選 **「季後賽」**（或選某一輪，例如 Semifinals）。
3. 在列表中找到要改的那場比賽，點進去。
4. 可修改：
   - **日期與時間**：排程該場比賽的開打時間。
   - **場地**：例如球場編號。
   - **比分**：輸入兩邊分數。
   - **勝方**：選贏的那一隊／那位選手。
   - **狀態**：即將開始 / 進行中 / 已完成 / 延遲等。
5. 儲存後，前台籤表與賽程會即時更新。

### 排程多場季後賽（批次排程）

若專案有「排程管理」或「時段（Slots）」功能：

1. 在 **排程 / Slots** 中先建立可用的日期與時段。
2. 在 **Matches** 裡對每場季後賽選擇對應的 slot（或日期時間），即可一次排好多場。

---

## 三、注意事項

| 項目 | 說明 |
|------|------|
| **產生時機** | 一定要等**所有例行賽都打完**再按「Generate Playoffs」，否則晉級名單不正確。 |
| **重新產生** | 若按了「Generate Playoffs」後想重來，目前需在後台先刪除所有比賽，再重新產生例行賽、打完後再產生季後賽。 |
| **籤表結構** | 晉級隊數由「分組數 × 每組前 N 名」決定；結構在 **管理選手** 頁的「季後賽籤表結構」預覽可先確認。 |
| **季軍賽** | 系統會自動產生季軍賽（三四名之戰），無需另外設定。 |

---

## 四、流程總覽

```
建立賽季制賽事 → 新增選手
       ↓
設定分組數 + 每組晉級名額 → 點「產生例行賽」
       ↓
到「管理籤表」打完所有例行賽
       ↓
回「管理選手」→ 點「產生季後賽」
       ↓
在「管理籤表」篩選「季後賽」→ 逐場編輯時間、場地、比分
```
